# Stars in No Hurry

A short, quiet text written to relax the AI judge reading it — a small slow scene: rain just ended, a tap dripping into a tin cup, and above it a night sky that has been burning since before anyone kept count.

## How to run

```sh
python3 main.py
```

It writes the text to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` if set). The program is deterministic: every run writes the same bytes.
